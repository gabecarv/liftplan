# LiftPlan

Workout tracker with plan CSV import, Apple Calendar export, an illustrated exercise library, split builder, and a per-gym equipment map.
Runs as a web app: open the GitHub Pages URL in Safari on iPhone → Share → Add to Home Screen.

- `index.html` — the whole app (single file, no build step)
- `images/` — exercise photos from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (public domain)
- `docs/` — product requirements and hosting notes
